## What shipped, file-by-file

### Core (platform-neutral)
- `coolstep/core/curve.py` — 8 composable policies, `compose_curve`,
  per-anchor idempotent. New fields on `CurveContext`: `conservative`,
  `workload_profile`, `heat_soak_index`.
- `coolstep/core/workload_profile.py` (new) — Profile enum + frozensets
  + `resolve_profile()`. Single source of truth — re-exports
  `WORKLOAD_CLASSES_HEADROOM = RENDER_CLASSES | GAME_CLASSES` so the
  curve module derives it.
- `coolstep/core/fingerprint.py` — added `heat_soak_index` feature via
  the existing `_slope()` OLS helper. Falls back to ΔT/Δload when
  cpu_power_pkg is zero (today's k10temp reality).
- `coolstep/core/backfill.py` — extended `_label_one` with
  `was_danger_vector`, `is_stable`, `equilibrium_rpm`. Idempotent.
- `coolstep/core/predictor.py` — `Prediction` gained
  `danger_neighbour_count` + `suggested_rpm`. `KnnPredictor.predict()`
  fires a second chroma query (`where={"is_stable": 1}`) for the
  RPM-target signal.
- `coolstep/core/decision.py` — `Thresholds.conservative_floor=0.45` +
  `Thresholds.conservative_prob_hint=0.2`. Daemon computes
  `conservative` boolean from these and forwards into curve context.
- `coolstep/core/event_segmentation.py` (new) — `EventSegmenter` state
  machine with three triggers: focus_change, load_jump, plateau_collapse.
- `coolstep/core/efficiency_calibration.py` (new) — stable-run analyser
  + append-only `data/efficiency_table.jsonl`. Daemon calls
  `_run_efficiency_pass` every 600 ticks.
- `coolstep/core/cluster_drift.py` (new) — `detect_cluster_drift()`
  read-only function over chroma. Per-workload Δ°C 24h-vs-prior.
- `coolstep/core/ewma_filter.py` (new) — confidence-adaptive alpha
  per-anchor smoothing. **Not wired into actuator yet** — see
  followup TODO.
- `coolstep/core/snapshot_archive.py` (new) — golden-state archive
  + `compute_drift(current, baseline)`. **Capture trigger not wired**
  — open question, see followup.

### Adapters
- `coolstep/adapters/collectors/linux_sysfs.py` — three-stage perf
  rework:
  - Stage 1: instance path cache (no globs in steady state)
  - Stage 2: `_FdCache` — `os.pread(fd, n, 0)` reuse
  - Stage 3: selective refresh — freq every 3 ticks, voltages every 5,
    platform_state every 30. /proc/stat + temps + powers stay per-tick.
  19.1 ms → 16.2 ms (~15 % saved, steady state).
- `coolstep/adapters/actuators/asusctl_fan_curve.py` — accepts the new
  `workload_profile` + `heat_soak_index` fields out of `curve_context`
  payload. Adaptive path otherwise unchanged.
- `coolstep/adapters/actuators/ryzenadj_cap.py` — docstring extended
  with sudoers retry + secure-boot blocker note (operational).
- `coolstep/adapters/storage/chroma.py` — `query_stable()` +
  `list_stable()` + `_normalise_metadata()` centralised type coercion.
  Added env hatch `COOLSTEP_CHROMA_DISABLED=1` to mask the known rust
  SEGV — daemon falls back to AlwaysIdleBaseline.

### Daemon
- `coolstep/daemon.py` —
  - `ensure_enabled()` call on every supporting actuator at startup
    (fixes `asusctl CPU enabled:false` regression).
  - `_recent_throttle_count()` helper for `Curve.recent_throttle_bump`.
  - `_reload_mode_from_state()` — already there from P2.3, unchanged.
  - `_quiet_safety_eject()` — already there from P2.3, now writes
    incident.
  - `_write_incident()` (P2.4) — unchanged.
  - `curve_ctx_payload` extended with `conservative`,
    `workload_profile`, `heat_soak_index`.
  - `EventSegmenter` instance + per-tick `feed()` updates
    `self._last_session_id`.
  - `_run_efficiency_pass()` every 600 ticks, appends to
    `data/efficiency_table.jsonl`.
  - `_dump_ml_state` surfaces `workload_label`, `session_id`,
    `danger_neighbour_count`, `suggested_rpm`.

## Known issues at end of session

- **Chromadb rust-bindings SEGV** under Python 3.14 — auto-restarts in
  crash-loop within ~12-13 s. Masked via `COOLSTEP_CHROMA_DISABLED=1`
  drop-in `60-chroma-disabled.conf`. Predictor falls back to
  `AlwaysIdleBaseline`; all KNN-dependent signals dormant
  (danger_neighbour_count = 0, suggested_rpm = None).
- **ryzenadj path** — sudoers file never created; even if it were,
  secure boot blocks the `/dev/mem` fallback. CAP_BOOST actuator
  stays dry-run.
- **EWMA filter, rpm_target policy, spike-trigger bypass,
  EventSegmenter persistence** — modules + data shipped, daemon
  wiring deferred. See `[[project-coolstep-p2_5-followup-todo]]`.

## Verification recipe

```bash
# Pytest (chroma-safe)
cd ~/coolstep
COOLSTEP_CHROMA_DISABLED=1 COOLSTEP_DECISIONS_LOG_DISABLED=1 \
    COOLSTEP_INCIDENTS_LOG_DISABLED=1 \
    .venv/bin/python -m pytest tests/ -q   # → 525 passed

# Live (collector + dashboard)
systemctl --user restart coolstep-collector coolstep-dashboard
sleep 80   # wait for CostTracker rolling-window to settle

curl -s http://127.0.0.1:18889/api/ml-state | jq '
  {tick, workload_label, session_id, danger_neighbour_count,
   suggested_rpm, collector_costs_us}'
# Expect: linux_sysfs ~16 ms, workload set, session_id non-null,
# danger=0 + suggested=null while chroma is disabled.

curl -s http://127.0.0.1:18889/api/profile
# Expect: {"profile": "code", "workload_class": "kitty"} (or similar)

curl -s -X POST http://127.0.0.1:18889/api/mode/quiet
sleep 2
journalctl --user -u coolstep-collector --since "5 seconds ago" -q \
    --no-pager | grep -E "mode flip|reduce_noise|APPLIED"
# Expect: cool→quiet flip + REDUCE_NOISE emission (subject to safety belt).

asusctl fan-curve --mod-profile Performance | grep -E "fan:|enabled:"
# Expect: CPU enabled: true, GPU enabled: true (Phase A ensure_enabled fix).
```
